# safe-time-bridge-32-bit
This is an ISO Safe Time Bridge 32 bit legacy test
Bootable 32-bit test image for PFRG Safe Time Bridge (legacy BIOS; USB stick or CD). SHA-256: d92e9f1947d5d9867aa9f4e1ce9e408a8c50caf8c66ca7b707ec91946d1d4957. Proven by booting this exact ISO in QEMU through its own menu: 122 of 122 tests passed, with every expected result reported (built from lab commit 46e235f on October 23, 2026; every scenario and its result is listed in TEST_RESULTS.md, because the test lab itself is private; controls, checks of the test machine and a recorded limit are counted separately from tests there). New in this image (October 23, 2026), most of it answering a review of the October 22 build by Nori, an AI reviewer (a Grok bot recruited by Jason McCoy) who tested the published ISO without the source code: a program started through stb_run now runs under two supervisors and a crossing guard that answer its own raw file-date system calls in program time (the known gap in the October 22 build), refuse and declare any attempt to set the clock, and close the other routes to true time (the boot time, the RTC device and files, socket timestamps); local time follows the true year's daylight-saving rules, and the image carries a current time-zone database for machines whose own is older; the shift must be whole 28-year cycles and a time before 1970 is refused; and the 2100-02-28 limit is tested on every path, including the kernel's own clock with no bridge running. Carried over from earlier builds: finding STB-CAL-001 (the 56-year shift's window ends at 2094-01-19 03:14:07 UTC; an 84-year shift carries programs to 2100-02-28, and past that date the helpers stop with no date); the fail-closed launcher, which refuses to start a program unless its helper matches the program's architecture and the system's own loader can load it; the kernel's clock shortcut (the vDSO) off in every boot entry; nftw, ftw and fts in program time; children through a dynamic 32-bit /bin/sh (2019 Debian dash); the 2019 Debian Redis 5 server as a long-running service; and shim 4, the clock coordinator, with a planned shift change from 28 to 56 years.
