# safe-time-bridge-32-bit
This is an ISO Safe Time Bridge 32 bit legacy test
Bootable 32-bit test image for PFRG Safe Time Bridge (legacy BIOS; USB stick or CD). SHA-256: 642bf0c1e3c6a04d5140a736ebca4c1fd157ee9cbce9bafca7290c16474036d7. Proven by booting this exact ISO in QEMU through its own menu: 71 of 71 scenarios passed (run https://github.com/Jason-McCoy/PFRG-32BIT-Test-Lab/actions/runs/39464632085, built from lab commit 920f777). New in this image (October 20, 2026): children through a dynamic 32-bit /bin/sh (2019 Debian dash), the 2019 Debian Redis 5 server as a long-running service, and shim 4, the clock coordinator, with a planned shift change from 28 to 56 years. Contains third-party software under its own licenses: Linux kernel and busybox (GPL-2.0, sources from Alpine Linux 3.22), glibc (LGPL-2.1, Ubuntu 24.04), and Debian 10 packages, each under the license in its Debian copyright file: coreutils and gawk (GPL-3.0), dash, Redis 5 and their libraries (every package, version and SHA-256 is listed in MANIFEST.txt; sources at sources.debian.org). Corresponding source for these components is available on request from Pre-Failure Research Group LLC.
