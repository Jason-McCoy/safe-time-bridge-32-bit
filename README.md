# safe-time-bridge-32-bit
This is an ISO Safe Time Bridge 32 bit legacy test
Bootable 32-bit test image for PFRG Safe Time Bridge (legacy BIOS; USB stick or CD). SHA-256: 66b932730ab26ec1a704f6057537eb3309f24a197537a4176e99e086f50c524b. Proven by booting this exact ISO in QEMU through its own menu: 107 of 107 scenarios passed (built from lab commit 411e5e9 on October 22, 2026; every scenario and its result is listed in TEST_RESULTS.md, because the test lab itself is private). New in this image (October 22, 2026): finding STB-CAL-001 is fixed and tested: the 56-year shift's window ends at 2094-01-19 03:14:07 UTC (not 2100), an 84-year shift carries programs to 2100-02-28, and past that date the helpers stop with no date rather than give a program a date that is one day off; and a fail-closed launcher (stb_run with stb_guard_exec) refuses to start a program unless its helper matches the program's architecture and the system's own loader can load it, then starts it under the guard's kernel filter, so a helper that still fails to load stops the program at its first clock read instead of letting it run on true time (the guard does not yet cover file-date reads; stated in TEST_RESULTS.md). Carried over from the October 20 builds: the kernel's clock shortcut (the vDSO) is off in every boot entry and the helper refuses to run while it is on; nftw, ftw and fts give program time; children through a dynamic 32-bit /bin/sh (2019 Debian dash); the 2019 Debian Redis 5 server as a long-running service; and shim 4, the clock coordinator, with a planned shift change from 28 to 56 years.
