# safe-time-bridge-32-bit
This is an ISO Safe Time Bridge 32 bit legacy test
Bootable 32-bit test image for PFRG Safe Time Bridge (legacy BIOS; USB stick or CD). SHA-256: b0a0bea0bba49eba4afbbca3d95340bf32c21c425ec4f4cb42d48aa4ebb07509. Proven by booting this exact ISO in QEMU through its own menu: 84 of 84 scenarios passed (built from lab commit 966c8d0; every scenario and its result is listed in TEST_RESULTS.md, because the test lab itself is private). New in this image (October 20, 2026, evening): every boot entry turns off the kernel's clock shortcut (the vDSO, kernel option vdso32=0), and the helper refuses to run while it is on, so a program started without the helper can no longer read true time unnoticed; the C library's directory walks (nftw, ftw and fts) now give program time, including on a post-2038 clock, where glibc's own 32-bit and 64-bit-time versions fail; and the image refuses to build with a test version of the helper. Carried over from the earlier October 20 build: children through a dynamic 32-bit /bin/sh (2019 Debian dash), the 2019 Debian Redis 5 server as a long-running service, and shim 4, the clock coordinator, with a planned shift change from 28 to 56 years. Contains third-party software under its own licenses: Linux kernel and busybox (GPL-2.0, sources from Alpine Linux 3.22), glibc (LGPL-2.1, Ubuntu 24.04), and Debian 10 packages, each under the license in its Debian copyright file: coreutils and gawk (GPL-3.0), dash, Redis 5 and their libraries (every package, version and SHA-256 is listed in MANIFEST.txt; sources at sources.debian.org). Corresponding source for these components is available on request from Pre-Failure Research Group LLC.
